TEEERA COD — مشروع أندرويد — محمد محمود — الإصدار 3.0
======================================================

ما يتضمنه:
- واجهة رعب حمراء، خطوط شاشة، وهج وخلفية متحركة.
- مؤثر صوت إلكتروني يُولَّد محليًا عند الضغط، مع كتم الصوت واهتزاز اختياري.
- قفل PIN أول استخدام: 4 إلى 8 أرقام، تجزئة PBKDF2 مع ملح عشوائي محفوظ محليًا.
- مكتبة أوامر وشروحات مضمنة تعمل دون إنترنت.
- تخصيص لون وخط الواجهة.
- قوالب HTML وPython وCSS قابلة للنسخ.
- معلومات الجهاز وحالة اتصال الشبكة.
- تكامل اختياري مع Termux لقائمة محددة من الأوامر فقط.

مهم:
- القفل حماية أساسية للتطبيق فقط وليس خزنة أسرار، وملفات التطبيق على جهاز مروّت أو مخترق قد تكون معرضة.
- تكامل Termux يعتمد على نسخة Termux التي تدعم RUN_COMMAND. يجب تثبيت Termux من مصدر موثوق، تفعيل allow-external-apps في ~/.termux/termux.properties، ثم إغلاق Termux وإعادة فتحه. قد يلزم منح الإذن للتطبيق، وقد تختلف أسماء الخدمة/الإعدادات حسب نسخة Termux.
- التطبيق لا ينفذ أي نص عشوائي من المستخدم؛ الأوامر المباشرة مقيدة بقائمة مراجعة.
- مكتبة الأوامر والتصميم يعملان محليًا بعد تثبيت APK. تحديث الحزم أو ping يحتاج الإنترنت.
- القوالب تُعرض وتُنسخ فقط؛ لا تحفظ ملفات المشروع تلقائيًا.
- مؤثر الصوت مولّد إلكترونيًا، ولا توجد ملفات موسيقى خارجية.
- معلومات الذاكرة/المساحة التفصيلية غير مضافة بسبب اختلاف صلاحيات أندرويد.

بناء APK:
المشروع يستخدم Android Gradle Plugin 8.7.3 وcompileSdk 35 وJDK 17.
الطريقة الأسهل والأكثر موثوقية هي Android Studio على كمبيوتر، لكن طلب الهاتف فقط ممكن مع إعداد Android SDK يدويًا في Termux، وهو إعداد طويل وقد لا يعمل على كل جهاز.

داخل Termux:
1) انسخ ZIP إلى مجلد التنزيلات.
2) نفّذ:
   termux-setup-storage
   pkg update
   pkg install unzip openjdk-17 gradle
   mkdir -p ~/projects
   cd ~/projects
   unzip ~/storage/downloads/TEEERA_COD_v3.zip
   cd TEEERA_COD_v3
3) تحتاج Android SDK Platform 35 وBuild Tools مناسبة وتعيين ANDROID_HOME أو ANDROID_SDK_ROOT؛ Gradle وحده لا يكفي. لا يوجد Gradle Wrapper مضمّن في هذه الحزمة.
4) بعد إعداد SDK بشكل صحيح:
   gradle assembleDebug
5) إذا نجح البناء:
   app/build/outputs/apk/debug/app-debug.apk
6) للتثبيت من مدير الملفات، افتح APK واسمح بالتثبيت من هذا المصدر عند الطلب.

التوقيع:
- APK debug يوقّعه Gradle تلقائيًا بمفتاح debug للاختبار.
- للنشر الرسمي، أنشئ مفتاح release خاصًا بك واحفظه في مكان آمن، ثم أنشئ توقيع release. لا تشارك ملف المفتاح أو كلمات مروره.

تشخيص:
- إذا ظهر SDK location not found، ثبّت Android SDK واضبط ANDROID_HOME.
- إذا ظهر SDK platform 35 missing، ثبّت platform 35.
- إذا فشل تشغيل Termux، افتح Termux يدويًا وراجع إعدادات السماح بالتشغيل الخارجي ونسخة Termux.
